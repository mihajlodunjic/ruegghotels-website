Self-hosted font assets, Fontsource packages 5.3.0. Original WOFF2 files, unmodified.

- Cormorant Garamond: variable weight 300–700, Latin normal + italic. https://fontsource.org/fonts/cormorant-garamond
- DM Sans: variable weight 100–1000, Latin normal. https://fontsource.org/fonts/dm-sans

Both are SIL Open Font License 1.1. The complete licenses are included alongside the font files.
Upstream: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond and https://github.com/google/fonts/tree/main/ofl/dmsans.
Fonts are served locally; no Google Fonts or other third-party runtime request is made.
